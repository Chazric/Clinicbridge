# ClinicBridge AI

Clinical encounter management and patient communication platform for iOS and Android (Flutter).
Publisher: RED REISHI LLC · Bundle/package ID: `com.redreishi.clinicbridge` · Support: redreishilife+clinicbridge@gmail.com

> Every patient encounter must be understood, communicated, organised and transferred with traceable clinical information.

**Status: v1 prototype.** Device-only (no backend, no EHR connection), synthetic demo data, not a medical device, not hospital-certified.

## Features
- **Clinical Truth Ledger** – provenance (patient-reported / clinician-observed / imported / AI-generated / translated / clinician-approved), verification state, append-only SHA-256 hash chain, amend/dispute/entered-in-error with reasons.
- **Medical interpreter** – 22 languages + dialects, on-device speech & ML Kit translation, back-translation, number/unit/drug/negation preservation checks, risk classification, teach-back, human-interpreter escalation (mandatory for consent & serious news).
- **Handoff** – SBAR and I-PASS, sender section review, meds/allergy verification, named-receiver acceptance, responsibility transfer only on acceptance, audit history.
- **Workflow intelligence** – missing data, allergy/medication conflicts and cross-reactivity, duplicate therapy, high-alert medicines, unsafe dose notation, conflicting weights, overdue tasks, duplicate patients.
- **Security** – AES-256-GCM vault (Keychain/Keystore key), PIN + biometrics, auto-lock, RBAC, hash-chained audit, FLAG_SECURE, no cloud backup, retention purge, crypto-shred erase, encrypted backups.
- **FHIR R4** bundle export with Provenance (base R4 / IPS / US Core / UK Core tags).

## Billing (clinic licences)

The app is free; real-patient mode needs a clinic licence. Clinics buy seats on the web (`server/`, Stripe Checkout):
$49 per clinician per month or $490 per year, 14-day trial, enterprise by quote. No purchase UI is in the app.

- `server/` — Node billing server (Render: `render.yaml`). Env: `STRIPE_SECRET_KEY`, `LICENCE_SIGNING_KEY`
  (Ed25519 PKCS8 base64, `npm run keygen`), `PUBLIC_BASE_URL`. Tests: `cd server && npm test`.
- After checkout the success page shows a licence key (`CB-XXXX-XXXX-XXXX-XXXX`, derived from the Stripe customer; only its hash is stored).
- The app sends only the licence key and a random install id to `/v1/billing/activate` and stores the server-signed
  licence, verified offline with `licencePublicKeyHex` in `app/lib/core/licence.dart`. One seat = one device; licences refresh every 30 days.
- Override the server URL with `--dart-define=CLINICBRIDGE_BILLING_URL=...`.

## Build
```
cd app
flutter pub get
flutter analyze && flutter test
flutter build appbundle --release      # Google Play (set android/key.properties or CLINICBRIDGE_KEY_PROPERTIES)
flutter build ipa --release            # App Store – macOS + Xcode, iOS 15.5+
```
`key.properties`: `storeFile`, `storePassword`, `keyAlias`, `keyPassword`. Without it, release builds are debug-signed (testing only).
